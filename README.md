# 8051-Assembly-Calculator

本项目为学校课程项目作业，谨慎参考。

## 实验任务
本实验旨在设计并实现一款基于51系列单片机的简易四则运算计算器系统。系统需在Proteus仿真环境中完成电路搭建，以4×4矩阵键盘作为输入模块实现数字及运算符号的输入操作，以LCD1602液晶显示器作为输出模块实现运算数据、操作符号及结果的可视化显示。该计算器系统应具备255以内整数的加、减、乘、除四则运算功能，并实现连续运算机制与运算异常（如溢出等）自动清零功能，为单片机应用系统的输入输出控制及逻辑运算设计提供实践载体。

## 功能要求
1.系统运行与显示性能：在Proteus仿真环境中可实现稳定运行，LCD1602液晶显示器显示信息清晰无闪烁，4×4矩阵键盘按键响应及时且输入逻辑准确，无误触发现象。

2.按键输入稳定性：采用延时的方法保证按键去抖动处理，设计单次触发机制，有效避免按键机械抖动导致的输入信号干扰，确保按键输入的稳定可靠性。

3.输入模块功能定义：以4×4矩阵键盘为输入设备，16个按键功能定义如下：数字键0～9、运算符号键“+”“-”“×”“/”、结果确认键“=”及系统清零键“CLR”，各按键功能映射关系明确且响应逻辑正确。

4.基础运算功能：支持-255~255范围内两个整数的单次加、减、乘、除四则运算，运算过程中需实时在LCD1602上显示当前输入的操作数与运算符号，运算完成后准确显示最终结果。

5.连续运算功能：支持连续运算模式，即上一次运算的有效结果可自动作为下一次运算的第一个操作数，用户无需重新输入该数值即可直接输入新的运算符号及第二个操作数，实现运算过程的连续性与便捷性。

6.异常处理机制：当运算过程中出现以下异常情况时，系统应触发错误警报（如LCD显示错误标识或特定提示信息），并自动执行清屏操作：①运算操作数超出[0,255]范围（溢出）；②运算结果超出[-255,255]范围（溢出）；③除法运算中除数为零；④单次运算式中运算符号个数超过1个（逻辑错误）。
